# خصوصية البيانات — مبادئ التصميم

**الحالة: PROPOSED.** لا يوجد حساب مستخدم أو Backend أو تخزين بيانات تشغيلية إنتاجي مثبت في `main`.

## مبادئ ملزمة عند بناء أي تخزين

- اجمع الحد الأدنى من البيانات اللازمة لغرض معلن.
- لا تجمع الاسم الحقيقي أو الموقع الدقيق أو جهات الاتصال إلا لضرورة واضحة وموافقة/أساس قانوني مناسب.
- استخدم معرفات مستعارة في سجلات اللعب والتجارب.
- حدد الغرض، الوصول، الاحتفاظ، الحذف، التصدير، وموقع المعالجة قبل التخزين.
- لا تضع بيانات شخصية أو أسراراً في Issues العامة أو artifacts أو logs.
- قيّد الوصول واحتفظ بسجل تدقيق مناسب، واستخدم التشفير أثناء النقل والتخزين عند الحاجة.

## قرارات مفتوحة

فئات البيانات، الأعمار/الموافقة، مزود الخدمة، منطقة البيانات، retention، deletion/export، analytics، telemetry، ومشاركة البيانات مع أطراف ثالثة. تحتاج هذه النقاط إلى مراجعة قانونية/خصوصية حسب الأسواق المستهدفة ولا تمثل هذه الوثيقة رأياً قانونياً أو شهادة امتثال.
