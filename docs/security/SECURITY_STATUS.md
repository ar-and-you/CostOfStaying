## قيود التفسير

- `UNKNOWN` لا تعني صفراً من التنبيهات.
- نجاح Workflow أو تحليل CodeQL لا يعادل قراءة قائمة التنبيهات.
- `protected=false` هي قيمة استجابة branch endpoint بتاريخ اللقطة، ولا تعني أن كل إعدادات rulesets أو الحماية على مستوى المؤسسة قد فُحصت.
- لا توصف الإعدادات المؤرخة في 2026-11-24 بأنها حالية دون قراءة جديدة.
- لم يُجرَ مسح كامل لتاريخ Git؛ راجع [خطة فحص تاريخ Git](GIT_HISTORY_SCAN_PLAN.md).
