# خطة فحص تاريخ Git بحثاً عن الأسرار

**الحالة:** PLANNED  
**تاريخ التسجيل:** 2026-11-28  
**المرجع:** `e7e5b5e54f46490c44aaf30888280d55239bb670`

## السياق

- محاولة المرحلة 76 لفحص تاريخ Git لم تكتمل بسبب تعذر حل DNS للوصول إلى `github.com`.
- لا يوجد مسح تاريخي مكتمل موثق لكل الفروع.
- لا توجد خطوة Gitleaks في Workflows الثلاثة المتتبعة وفق فحص 2026-11-28.
- لا يجوز إعلان تاريخ المستودع خالياً من الأسرار.

## خطة التنفيذ

1. اختيار إصدار ثابت من **Gitleaks** أو **TruffleHog** وتثبيته ببصمة/مرجع إصدار قابل للتحقق قبل التشغيل؛ لا تعتمد إصداراً عائماً.
2. تحديد النطاق الفعلي للفروع والوسوم والمراجع البعيدة، بما فيها `main` و`security/core-trust-boundaries-phase0`، وتسجيل قائمة المراجع التي شملها الفحص.
3. تشغيل المسح على كامل تاريخ Git للمراجع المحددة، عبر Runner يملك اتصالاً موثوقاً أو mirror محلياً مكتمل التاريخ.
4. حفظ تقرير JSON في مساحة آمنة، ونشر ملخص لا يكشف قيمة أي سر.
5. فرز كل اكتشاف وتوثيق القرار؛ تدوير/إبطال أي بيانات اعتماد مكشوفة وفق إجراء الاستجابة للحوادث.
6. تسجيل الأداة وإصدارها وبصمتها، ونطاق المراجع، وSHA/معرفات refs، وتاريخ التشغيل، وRun ID، والنتيجة.
