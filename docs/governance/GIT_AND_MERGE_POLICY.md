# سياسة Git والدمج

**الحالة:** ACTIVE وفق سياسة `ROADMAP.md` وطلب المالك الحالي.

1. `main` هو الفرع الدائم والمرجع الرسمي للملفات المتتبعة والتاريخ.
2. التغييرات المعتمدة تدخل مباشرة إلى `main` وفق السياسة الحالية؛ لا تنشئ فروع مهام أو PRs كمسار افتراضي دون تغيير صريح من المالك.
3. يحظر `force push`، وإعادة كتابة التاريخ، واستبدال `.git`، وحذف `main`.
4. لا تتجاوز branch protection أو قواعد GitHub. إذا منعت حماية مفعلة الدفع، توقف ووثق سبب الرفض.
5. مشغلات PR الموجودة في CI لا تعني اعتماد PR كمسار عمل دائم.
6. في إعادة فحص GitHub بتاريخ 2026-11-24، لم تكن حماية `main` مفعّلة وكانت قائمة repository rulesets فارغة. هذه ملاحظة حالة وليست قراراً بتعطيل الحماية إلى الأبد.
7. إذا تقرر اعتماد PRs أو حماية الفرع، يجب تحديث `ROADMAP.md` و`CONTRIBUTING.md` و`AGENTS.md` وهذا الملف في commit واحد، وضبط required checks بناءً على أسماء jobs الفعلية.
8. لا ترفع ZIP أو `.git` من الأرشيف داخل المستودع. استورد الملفات المحددة بعد مقارنة البصمات والفرق.
9. لا تسجل commit ناجحاً قبل قراءته من GitHub والتحقق من SHA والملفات.
