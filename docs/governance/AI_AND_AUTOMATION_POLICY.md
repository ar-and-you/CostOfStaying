# سياسة الوكلاء والذكاء الاصطناعي والأتمتة

**الحالة:** ACTIVE.

1. اقرأ `AGENTS.md` والوثائق المعيارية قبل أي تغيير.
2. لا تدّعِ قراءة ملفات أو تشغيل أوامر لم تُنفذ فعلياً.
3. لا تستخدم مخرجات ملخصات المحادثات أو تقارير سابقة كبديل عن الملف أو الشجرة الحالية.
4. لا ترفع ملفات أو تنفذ عمليات GitHub كتابة إلا ضمن نطاق طلب المالك، وبعد فحص الفرع وHEAD والفرق.
5. عند استخدام أدوات أو APIs، سجّل SHA والنتيجة الفعلية والقيود.
6. لا تحوّل نصوص الأرشيف إلى قرارات نافذة بمجرد نقلها.
7. لا تفصح عن الأسرار أو بيانات المستخدمين ولا تنشئ أسراراً أو قيم اعتماد وهمية.
8. لا تنفذ تغييرات قواعد اللعب أو التوازن أو الشبكة أو SDK خارج نطاق قرار واضح.
9. إذا تعذر التحقق أو الكتابة، أوقف العملية وأنشئ artifact للتطبيق اليدوي، ولا تدّعِ الرفع.
10. لا تستخدم أدوات خارجية مدفوعة أو حسابات أو خدمات تتطلب صلاحيات غير متاحة دون موافقة المالك.


## 11. نموذج تشغيل الوكلاء والمهارات

تُقرأ هذه السياسة مع [نموذج تشغيل الوكلاء](../ai/AI_AGENT_OPERATING_MODEL.md) و[سياسة حوكمة الوكلاء والسلامة](../ai/AI_AGENT_GOVERNANCE_POLICY.md) و[سجل الأدوار](../ai/AGENT_ROLE_CATALOG.md). المهارات المحمولة في `.agents/skills/` إرشادات تنفيذية فقط ولا تمنح صلاحية وصول أو كتابة أو تشغيل. ابدأ بالقراءة فقط، واطلب موافقة مستقلة لكل صلاحية كتابة/تنفيذ/عملية GitHub بعيدة، ولا تعتبر أسماء مزودي النماذج دليلاً على اتصالهم أو توفرهم. يظل مالك المشروع صاحب القرار النهائي، ولا تُحسم خلافات النماذج بالتصويت.
