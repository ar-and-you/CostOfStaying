# الأرشيف التاريخي — غير نافذ

كل ما يوجد داخل `docs/archive/` مواد حفظ تاريخية من النسخ والأرشيفات وتقارير محلية ومحاكاة آلية وسجلات ADR مرشحة. قد توجد فيها ادعاءات قديمة أو قرارات متعارضة أو links نسبية لا تعمل بعد نقلها.

لا تستخدم هذه المواد كسياسة حالية أو دليلاً على حالة `main`. عند الرغبة في إحياء اقتراح، أعد مراجعته مع الشفرة الحالية وسجل ADR/Policy جديداً بموافقة المالك.

المصادر شملت أرشيفات ZIP متعددة؛ جرد الأسماء والأحجام والبصمات في `SOURCE_ARCHIVE_INVENTORY.md`. لم تُضمّن ملفات `.git` أو الشفرة أو الاختبارات أو مخرجات build في هذه الحزمة الوثائقية.
