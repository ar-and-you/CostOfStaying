# الأرشيف التاريخي — غير نافذ

كل ما يوجد داخل `docs/archive/` مواد حفظ تاريخية من النسخ والأرشيفات وتقارير محلية ومحاكاة آلية وسجلات ADR مرشحة. قد توجد فيها ادعاءات قديمة أو قرارات متعارضة أو روابط نسبية لا تعمل بعد نقلها.

لا تستخدم هذه المواد كسياسة حالية أو دليلاً على حالة `main`. عند الرغبة في إحياء اقتراح، أعد مراجعته مع الشفرة الحالية وسجل ADR/Policy جديداً بموافقة المالك.
