# توافق الأجهزة — خطة تحقق مستقبلية

> تنبيه حوكمي: أرقام ADR المشار إليها في نسخ سابقة هي مواد أرشيفية ما لم توجد في `docs/adr/` بحالة مقبولة على `main`.

**الحالة:** `TBD`. لا يوجد Unity build أو APK/AAB أو iOS build أو جهاز مقاس في `main`.

لا تعتمد اسماً تجارياً لجهاز أو إصدار نظام كحد أدنى دون build قابل للتشغيل وقياسات. عند وجود prototype:

- حدد SKU والذاكرة والمعالج وGPU وإصدار النظام.
- اختبر فئات منخفضة ومتوسطة وعالية لكل منصة مستهدفة.
- سجل وقت الإقلاع وFPS وPSS/الذاكرة والحرارة واستهلاك الطاقة ومعدل الإطارات المتدهور.
- وثق إعدادات الجودة والدقة والمشهد ومدة الاختبار.
- لا تعمم نتيجة جهاز واحد على كامل الفئة.

Android هو الهدف الأول في التصور؛ iOS scope وشروط النشر لم تُعتمد. لا توجد حالياً مصفوفة توافق أو نتائج قياس.
