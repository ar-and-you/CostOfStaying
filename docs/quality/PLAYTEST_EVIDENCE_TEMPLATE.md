# نموذج توثيق جلسة اختبار لعب بشرية

**الحالة:** نموذج فارغ للاستخدام عند إجراء جلسة بشرية فعلية. لا يحتوي على نتائج، ولا يُعد دليلاً على إجراء أي جلسة.

> الخصوصية: لا تسجل أسماء المشاركين أو عناوينهم أو أرقام هواتفهم أو حساباتهم أو أي بيانات تعريفية مباشرة. استخدم رمز جلسة مستعاراً فقط. لا تضع السجلات الخام أو الإجابات الحرة التي قد تكشف الهوية في Git.

## ب. ثبات التجربة

- [ ] تم استخدام شرح موحد لا يلقن استراتيجية.
- [ ] تم تثبيت إصدار القواعد والقيم طوال العينة.
- [ ] لم تُجرَ تغييرات على build أو الإعدادات أثناء الجلسة.
- [ ] تم توضيح غرض الاختبار والبيانات المجموعة والمشاركة الطوعية.
- [ ] لم تُجمع معلومات تعريفية غير لازمة.
- [ ] تم تخزين السجل الخام خارج Git في موقع خاص محدود الوصول.

إذا تغير إصدار القواعد أو build أثناء الجلسة، وثّق التغيير هنا وحدد ما إذا كانت الجلسة صالحة للتحليل.

## ز. قواعد التجميع

- احفظ نسخة السجل الخام في مخزن خاص خارج Git وفق سياسة الاحتفاظ والحذف التي يحددها مالك المشروع.
- انقل إلى تقرير التحليل إحصاءات مجمعة ومجهّلة فقط؛ لا ترفع السجلات الخام أو الإجابات الحرة الحساسة.
- لا تُحسب الجلسة ضمن الحد الأدنى البشري إلا بعد مراجعة صلاحيتها.
- لا تُحسب جلسات المحاكاة الآلية أو smoke tests أو جلسات المطور الاصطناعية ضمن العينة البشرية.
- بلوغ عشر جلسات صالحة شرط للعينة المحددة في `PLAYTEST_PLAN.md` وليس موافقة تلقائية على قواعد اللعبة أو توازنها.
