# خريطة الأدوات — الوضع الفعلي والفجوات

**تاريخ الجرد:** 2026-11-22

هذه الخريطة تفرق بين الملفات الموجودة فعلاً في فرع المشروع والأدوات المقترحة أو التي لم تُستورد بعد.

## 1. الموجود في الشجرة الحالية

| المجال | الأداة/المكوّن | الحالة |
|---|---|---|
| إدارة المصدر | Git وGitHub | مستودع عام وفرع `main` |
| Domain tests | NUnit / .NET 8 | مشروع واختبارات موجودة؛ CI ناجح على SHA `b16fe9916b03b25db575fed5eac495182605725c` |
| Core tests | NUnit / .NET 10 | مشروع واختبارات منفصلة؛ CI ناجح على SHA نفسه |
| محاكاة التوازن | Python simulator وpresets وsweep | موجودة؛ النتائج استكشافية فقط |
| محاكاة جلسات | `tools/playtest/run_sessions.py` | موجودة؛ ليست جلسات بشرية ولا جزءاً من CI |
| CI — Domain/Python | `.github/workflows/ci.yml` | موجود؛ آخر تشغيل على SHA الحالي نجح |
| CI — Core | `.github/workflows/core-ci.yml` | موجود؛ آخر تشغيل على SHA الحالي نجح |

## 2. فجوات لم تُفعّل أو لم تُستورد

| الأداة | الغرض | شرط الإدخال |
|---|---|---|
| `tools/audit.py` | تدقيق الروابط والكتالوج والحالات | مراجعة توافقه مع الوثائق الحالية ثم إدخاله |
| GitHub configuration tests | اختبار إعدادات GitHub والحوكمة | إدخال الإعدادات التي تعتمد عليها أولاً |
| actionlint وzizmor | فحص تعريفات GitHub Actions | تثبيت الإصدارات ومراجعة النتائج |
| gitleaks | كشف الأسرار في الشجرة والتاريخ | workflow أمني مستقل ومراجعة الإعدادات |
| CodeQL | تحليل ساكن أمني | workflow مستقل وصلاحيات `security-events: write` عند الحاجة |
| Dependabot | تحديث الاعتماديات | التحقق من مسارات المشاريع والحزم |
| CODEOWNERS | تحديد مراجعي الملكية | تحديد مالك/فريق حقيقي والتحقق من المسارات |
| Rulesets | حماية الفرع | قرار مالك ومطابقة أسماء الفحوص مع jobs الفعلية |
| Unity Test Framework / GameCI | بناء واختبار Unity | وجود مشروع Unity وإصدار محرر وتراخيص |
| Android SDK/NDK وPerfetto | بناء وقياس Android | وجود تطبيق قابل للبناء أولاً |

## 3. التحليل والاختبار

- استخدم اختبارات NUnit القائمة كخط أساس قبل إدخال محللات إضافية.
- يمكن تقييم Roslyn analyzers وNetArchTest بعد تحديد الحدود المعمارية النهائية.
- لا تضف خدمات مدفوعة قبل توثيق الحاجة والتكلفة والترخيص.
- لا تعامل `test_parity.py` على أنه اختبار تطابق C# وPython؛ هو اختبار انحدار لمحاكي Python فقط.
- لا تعامل سجلات المحاكاة على أنها دليل توازن معتمد؛ يتطلب ذلك جلسات بشرية موثقة.
- لا يشغّل CI مولد الجلسات الاصطناعية `tools/playtest/run_sessions.py` ولا أداة تدقيق غير موجودة.
- لا تسجل نتائج CI أو الأمان على أنها ناجحة قبل ظهور تشغيل حقيقي مرتبط بـcommit SHA.

## 4. مبادئ الأمان

لا تحفظ مفاتيح API أو أسرار النشر أو شهادات التوقيع أو ملفات `.env` داخل Git. لا يغني `.gitignore` عن مراجعة التاريخ والملفات المتتبعة. لا يوجد حالياً ماسح أسرار أو تحليل ساكن أمني مفعّل في GitHub Actions.
