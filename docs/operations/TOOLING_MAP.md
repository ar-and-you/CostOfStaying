# خريطة الأدوات — الوضع الفعلي والفجوات

**تاريخ الجرد:** 2026-11-21

هذه الخريطة تفرق بين الملفات الموجودة فعلاً في فرع المشروع والأدوات التي ظهرت في الحزم المرجعية ولم تُستورد بعد.

## 1. الموجود في الشجرة الحالية

| المجال | الأداة/المكوّن | الحالة |
|---|---|---|
| إدارة المصدر | Git وGitHub | مستودع عام وفرع `main` |
| Domain tests | NUnit / .NET 8 | مشروع واختبارات موجودة |
| Core tests | NUnit / .NET 10 | مشروع واختبارات منفصلة موجودة |
| محاكاة التوازن | Python simulator وpresets وsweep | موجودة؛ النتائج استكشافية فقط |
| محاكاة جلسات | `tools/playtest/run_sessions.py` | موجودة؛ ليست جلسات بشرية |
| CI — Domain/Python | `.github/workflows/ci.yml` | إعداد مضاف؛ بانتظار التحقق من تشغيل GitHub على SHA محدد |
| CI — Core | `.github/workflows/core-ci.yml` | إعداد مضاف؛ بانتظار التحقق من تشغيل GitHub على SHA محدد |

## 2. فجوات لم تُستورد بعد

| الأداة | الغرض | شرط الإدخال |
|---|---|---|
| `tools/audit.py` | تدقيق الروابط والكتالوج والحالات | مراجعة توافقه مع الوثائق الحالية ثم إدخاله |
| GitHub configuration tests | اختبار إعدادات GitHub والحوكمة | إدخال الإعدادات التي تعتمد عليها أولاً |
| `set_owner.py` وCODEOWNERS template | إعداد CODEOWNERS | تحديد مالك/فريق حقيقي والتحقق من المسارات |
| gitleaks وCodeQL | كشف الأسرار وثغرات الكود | workflow أمني مستقل وتثبيت الإصدارات والصلاحيات |
| Dependabot | تحديث الاعتماديات | التحقق من مسارات المشاريع والحزم |
| Rulesets | حماية الفرع | قرار مالك ومطابقة أسماء الفحوص مع jobs الفعلية |
| Unity Test Framework / GameCI | بناء واختبار Unity | وجود مشروع Unity وإصدار محرر وتراخيص |
| Android SDK/NDK وPerfetto | بناء وقياس Android | وجود تطبيق قابل للبناء أولاً |

## 3. التحليل والاختبار

- استخدم اختبارات NUnit القائمة كخط أساس قبل إدخال محللات إضافية.
- يمكن تقييم Roslyn analyzers وNetArchTest بعد تحديد الحدود المعمارية النهائية.
- لا تضف خدمات مدفوعة قبل توثيق الحاجة والتكلفة والترخيص.
- لا تعامل `test_parity.py` على أنه اختبار تطابق C# وPython.
- لا تعامل سجلات المحاكاة على أنها دليل توازن معتمد؛ يتطلب ذلك جلسات بشرية موثقة.
- لا يشغّل CI مولد الجلسات الاصطناعية `tools/playtest/run_sessions.py` ولا أداة تدقيق غير موجودة.
- لا تسجل نتائج CI أو الأمان على أنها ناجحة قبل ظهور تشغيل حقيقي مرتبط بـcommit SHA.

## 4. مبادئ الأمان

لا تحفظ مفاتيح API أو أسرار النشر أو شهادات التوقيع أو ملفات `.env` داخل Git. لا يغني `.gitignore` عن مراجعة التاريخ والملفات المتتبعة. فحص الأنماط المحدود ليس بديلاً عن ماسح أسرار متخصص.
