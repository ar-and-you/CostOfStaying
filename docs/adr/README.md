# سجل القرارات المعمارية (ADR)

## الحالة في `main`

اعتباراً من الالتزام الذي أضاف المرحلة 71 (`565f0443d21a38fc47e94945bbfb5cb73951335f`) لا يزال هذا المجلد يحتوي على `.gitkeep` و`README.md` و`ADR_TEMPLATE.md` فقط؛ ولا توجد سجلات ADR مقبولة. الفهرس والقالب لا يشكلان قراراً معمارياً.

تحتوي الأرشيفات المرجعية على سجلات متنافسة، بما فيها سجلان مختلفان برقم ADR-005 وفجوة ADR-024. لم تُستورد هذه السجلات ولم تُعد ترقيمها. راجع [المرحلة 71 — تطبيع فهرس المرشحات والتعارضات](../operations/ARCHIVE_RECONCILIATION_STAGE71_ADR_CATALOGUE_NORMALIZATION_2026-11-27.md) و[المرحلة 22 — فرز حوكمة ADR الأرشيفية](../operations/ARCHIVE_RECONCILIATION_STAGE22_GOVERNANCE_ADR_TRIAGE_2026-11-27.md).

## الضوابط الحاكمة

- مالك المشروع هو جهة اعتماد القرارات المعمارية طويلة الأثر؛ راجع `docs/governance/PROJECT_GOVERNANCE.md`.
- بوابة مصالحة واعتماد فهرس ADR هي D1، وحالتها `OPEN_OWNER_DECISION` في `docs/governance/OPEN_DECISION_REGISTER.md`.
- يبقى Domain وCore مشروعين منفصلين؛ لا تبدأ ترحيلاً أو توحيداً قبل اعتماد قرار وخطة واضحة.
- لا تعتمد قواعد اللعب أو أرقام التوازن من مواد أرشيفية أو محاكاة وحدها.
- سجّل كل ADR جديد بحالة صريحة (`PROPOSED` أو `ACCEPTED` أو `SUPERSEDED` أو `REJECTED`)، وتاريخ، ومالك القرار، والسياق، والبدائل، والنتائج، وروابط التنفيذ والاختبارات.

## تقاطع عقود Core مع الأرشيف

راجع [مصفوفة تغطية ADR-008..020](../operations/ARCHIVE_RECONCILIATION_STAGE60_LEGACY_CORE_ADR_COVERAGE_2026-11-27.md). بعض هذه العقود لها تطبيقات واختبارات في Core الحي، لكن هذا لا يجعل نصوص ADR الأرشيفية مقبولة على main. وجود primitives لا يثبت وجود transport adapter أو credential provider أو gameplay authorization policy أو persistence.

## شروط استيراد أي قرار

1. جرد كل نسخة من مصادرها وربطها ببصمة المصدر وcommit/التاريخ إن توفر.
2. حل تعارض الأرقام والعناوين وتحديد المرجع والسلطة دون حذف النسخ التاريخية.
3. مقارنة القرار المرشح مع الكود ومواصفات اللعب الحالية.
4. طلب اعتماد المالك للقرارات التي تختار حدود Domain/Core أو سياسة الفروع أو قواعد اللعب.
5. استيراد قرار واحد متسق في سجل مستقل، ثم تحديث هذا الفهرس و`docs/README.md` و`ROADMAP.md` وسجل القرارات المفتوحة.

حتى اكتمال هذه الخطوات، حالة المصالحة المعمارية `TBD`؛ لا تصف مجموعة الأرشيف بأنها الحوكمة النشطة.
