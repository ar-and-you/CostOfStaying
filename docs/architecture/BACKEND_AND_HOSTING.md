# Backend والاستضافة — قرار غير محسوم

**الحالة: TBD.** لا يوجد مزود Backend مختار أو Dedicated Server إنتاجي أو بيئة استضافة تشغيلية في `main`.

## حدود الوضع الحالي

- `Domain` و`Core` مكتبتان .NET؛ لا تُعد أي منهما خادماً منشوراً.
- لا يوجد transport adapter أو عملية Dedicated Server قابلة للتشغيل.
- لا يوجد مزود حسابات أو مطابقة أو تخزين إنتاجي مختار.
- لا توجد بيانات تشغيلية أو مقاييس إنتاجية يمكن استخدامها للمقارنة بين المزودين.

## خيارات مستقبلية للمقارنة

لم تُختَر خدمة. عند وجود prototype، يمكن مقارنة الاستضافة الذاتية وخدمات multiplayer managed بحسب:
- زمن الاستجابة وتوزيع المناطق الجغرافية.
- تكلفة التشغيل في أحجام اللعب المتوقعة وسيناريوهات الذروة.
- دورة حياة الخادم، autoscaling، health checks، وإعادة التشغيل.
- قابلية نقل الخادم والبيانات وتكلفة الخروج من المزود.
- observability، backups، recovery، incident response.
- متطلبات الترخيص والخصوصية وموقع البيانات.

## بوابة الاختيار

لا تختَر مزوداً قبل وجود prototype قابل للقياس، وتقدير تكلفة، ومراجعة بيانات/خصوصية، وخطة تعطل/استعادة، وADR مقبول يحدد النطاق والبدائل وخطة التراجع. لا تُضف خدمات متعددة إلى MVP دون متطلب مثبت.
