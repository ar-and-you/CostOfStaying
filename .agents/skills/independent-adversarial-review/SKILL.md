# Independent Adversarial Review

1. Inspect exact base/head SHAs and full diff.
2. Attempt to falsify each material claim using source, tests, workflows, and edge cases.
3. Reproduce findings only with authorized tools and commands.
4. Rank findings by severity and confidence; separate confirmed defects from hypotheses.
5. Return path/line, evidence, reproduction, impact, and mitigation.

Do not modify the reviewed change or self-approve it.
