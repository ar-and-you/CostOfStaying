# Repo Baseline Audit

1. Read `AGENTS.md`, `README.md`, `docs/README.md`, `CONTRIBUTING.md`, `ROADMAP.md`, and relevant policies.
2. Record repository, branch, HEAD SHA, working-tree state if available, and inspected paths.
3. Inspect project files, workflows, tests, manifests, and current docs; do not infer absent files from archives.
4. Separate verified facts, historical facts, proposals, and unknowns.
5. Return a concise baseline table and risk list with path/SHA evidence.

Do not edit, run commands, or make remote writes unless separately authorized.
