# Documentation Governance

1. Establish exact repository SHA and read governing instructions.
2. Traverse documentation from `docs/README.md`; identify broken links, orphans, duplicates, and stale references.
3. Compare claims with live code, tests, workflows, and policy sources.
4. Preserve `PROPOSED`, `ACCEPTED`, `IMPLEMENTED`, `VERIFIED`, and `TBD` distinctions.
5. Report findings with exact paths/lines, evidence, severity, and minimal corrections.

Do not resolve owner-only policy conflicts or import archive decisions as active.
